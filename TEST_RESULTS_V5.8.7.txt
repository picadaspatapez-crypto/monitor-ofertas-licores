Root cause
==========
The cross-store stage selected Product with JOIN + DISTINCT. Product contains JSON column data_quality_issues. PostgreSQL cannot compare json values for DISTINCT and raised psycopg.errors.UndefinedFunction.

Fix
===
Use a correlated EXISTS subquery to select products observed in the requested scrape runs. This returns each Product once without requiring equality on JSON columns.
