# v5.5.0 — Price Contexts & La Vinoteca

## Objetivo

Expandir cobertura sin contaminar el comparador público y preparar el sistema para precios condicionados por membresías, tarjetas o cupones.

## La Vinoteca

Fuente primaria: VTEX Catalog Search público (`/api/catalog_system/pub/products/search`).

Se extraen por SKU:

- nombre;
- URL;
- precio vigente;
- precio de lista;
- SKU;
- EAN cuando está disponible;
- disponibilidad.

La paginación usa rangos de 50 productos y corta ante respuesta vacía, HTTP 416 o repetición estructural.

## CAV diagnóstico

El collector recorre el catálogo público usando los parámetros de búsqueda visibles del sitio y separa explícitamente:

- `Normal` → `PUBLIC / public`;
- `Oferta` → `SALE / public_offer`;
- `Socio` → `MEMBER / cav_member`, con elegibilidad requerida.

CAV queda registrado con:

```text
comparison_enabled=false
diagnostic_mode=true
```

Por diseño no puede alterar el comparador, buscador, histórico público ni favoritos.

## Modelo de precios contextuales

### product_price_quotes

Representa el último precio vigente por publicación y contexto.

Clave lógica:

```text
product_id + price_type + audience_key
```

Tipos iniciales:

```text
PUBLIC
SALE
MEMBER
CARD_PROMO   # preparado
COUPON       # preparado
```

### price_quote_observations

Historial inmutable desde v5.5.0 para cada contexto.

El historial público anterior sigue conservado en `price_observations`.

## Vista personal

`personal_opportunity_snapshots` es una capa separada. No reemplaza `opportunity_snapshots`.

El preview personal admite `PUBLIC`, `SALE` y `MEMBER`. Para tiendas en diagnóstico solo acepta `MEMBER`, evitando que el precio normal de CAV se cuele en una ruta pública por error.

No se generan alertas automáticas desde esta vista en v5.5.0. Primero se observarán varios ciclos de CAV.

## Activación futura de CAV

Una futura v5.6 puede cambiar CAV a producción cuando se confirme durante varios ciclos:

- estabilidad del catálogo;
- clasificación correcta de Oferta vs Socio;
- persistencia de stock;
- matching confiable;
- ausencia de promociones condicionadas no detectadas.

Hasta entonces la fuente se considera diagnóstico con valor informativo personal.
