# v5.8.4 — Licor3B Title Integrity Guard

## Causa

El precio y la URL eran correctos, pero la tarjeta del catálogo de Licor3B podía incluir texto de más de un producto. Como el nombre contaminado entraba al catálogo canónico, el radar mostraba una identidad falsa aunque el winner fuese una botella individual válida.

## Defensa en profundidad

1. El collector contrasta el título visible con el slug del producto.
2. Solo usa el slug si hay fuerte superposición de identidad y exceso evidente de texto ajeno.
3. Un repair pass corrige filas Licor3B ya persistidas.
4. Se reconstruye el nombre canónico de masters afectados.
5. Se purgan snapshots derivados para recalcularlos.
6. `/radar` y `/minimos` aplican un guard vivo mientras quede algún snapshot viejo.
